# 📄 ขอบเขตงานและเงื่อนไขการส่งมอบ (Scope of Work) — ร้าน pakzy.o

เอกสารฉบับนี้สรุปขอบเขตงานที่พัฒนาและส่งมอบทั้งหมด ฟีเจอร์พิเศษ (ของแถม) เงื่อนไขการดูแลแก้ไขหลังส่งมอบ และข้อจำกัดของระบบ เพื่อให้เข้าใจตรงกันอย่างชัดเจนค่ะ ♡

---

## 1. สิ่งที่ส่งมอบในโปรเจกต์นี้ (Deliverables)

### 1.1 ระบบหน้าบ้านสำหรับลูกค้า (Storefront)
1. **หน้าแรก (`/`):**
   - Hero Section เอกลักษณ์ **"ตัวอักษรคือตัวเอกของร้าน"** ชื่อร้าน `pakzy♡o` ขนาดใหญ่สลับฟอนต์อัตโนมัติและตอบสนองตามการเลื่อนเมาส์/แตะลากบนมือถือ
   - ป้ายไฟแสดงสถานะคิวงานของร้าน (เปิดรับคิว / คิวแน่น / ปิดรับชั่วคราว)
   - กรอบโชว์โปรไฟล์/รูปร้าน `@pakzy.o` สไตล์มินิมอล
   - แถบข้อความวิ่งสลับฟอนต์ของร้าน (Marquee Strip)
   - การ์ดสินค้าและฟอนต์สไตล์สติกเกอร์ไดคัท (Die-cut Sticker Card)
   - สไลเดอร์เปรียบเทียบผลงานก่อน–หลัง (Before / After Slider)
   - เส้นขั้นตอนการสั่งงาน 4 ขั้นตอนที่วาดตามการเลื่อนหน้าจอ (Scroll-drawn SVG Path)
2. **หน้ารวมบริการและฟอนต์ (`/products`) & หน้ารายละเอียด (`/products/:id`):**
   - กรองตามหมวดหมู่ (บริการออกแบบ / ฟอนต์ลายมือ) และค้นหาด้วยคำสำคัญได้ทันที
   - แสดงแกลเลอรีรูปภาพ รายละเอียดสิ่งที่จะได้รับ และปุ่มหยิบใส่รายการสั่งซื้อ
3. **หน้าทดลองพิมพ์ฟอนต์ & เปรียบเทียบ A/B (`/font-tester`):**
   - พิมพ์ข้อความภาษาไทย–อังกฤษเพื่อดูตัวอย่างฟอนต์แบบเรียลไทม์ (ไม่มีปุ่มดาวน์โหลดฟอนต์)
   - ปรับขนาดตัวอักษร ระยะห่างบรรทัด การจัดวาง และสีกระดาษพื้นหลัง
   - โหมดเปรียบเทียบฟอนต์ **A/B (วางคู่กัน)**, **โหมดสไลเดอร์เทียบ A/B**, และ **โหมดจำลองป้ายร้าน / Rich Menu**
4. **หน้าแบบทดสอบ "ฟอนต์ไหนคือคุณ" (`/font-quiz`):**
   - แบบทดสอบ 4 คำถามวิเคราะห์สไตล์แบรนด์ แนะนำฟอนต์ที่เหมาะกับลูกค้า พร้อมบันทึกการ์ดผลลัพธ์เป็นรูปภาพ `.PNG` และแชร์ต่อได้ทันที
5. **หน้าผลงานร้าน (`/portfolio`), หน้ารีวิวลูกค้า (`/reviews`), และหน้าติดต่อร้าน (`/contact`):**
   - แสดงคะแนนรีวิวเฉลี่ย แถบสถิติดาว และฟอร์มส่งรีวิวพร้อมระบบป้องกันสแปม
   - แสดงช่องทางติดต่อทั้งหมด (ซ่อนช่องทางที่ว่างให้อัตโนมัติ)
6. **ระบบสั่งซื้อและส่งบรีฟงาน (`/order`):**
   - เลือกหลายรายการ ปรับจำนวน ใส่หมายเหตุรายชิ้น และกรอกบรีฟงาน
   - แสดง **การ์ดใบเสร็จสรุปคำสั่งซื้อ** พร้อมตราประทับ `"ขอบคุณค่ะ ♡"` และปุ่มบันทึกรูปใบเสร็จ `.PNG`
   - บันทึกออเดอร์ลงฐานข้อมูล Cloudflare D1 อัตโนมัติ พร้อมคัดลอกข้อความสรุปและเด้งเปิดแชต **LINE Official Account (`@280npxvj`)** ทันที
   - รองรับการกรอกรหัสสมาชิกเพื่อสะสมแต้ม พร้อมแสดงคะแนนที่จะได้รับล่วงหน้า
7. **หน้าระบบสะสมแต้มออนไลน์ (`/points`):**
   - สมัครเปิดบัตรสมาชิกฟรีใน 1 นาที โดยไม่ต้องใช้อีเมลหรือรหัสผ่านยาว รับรหัสสมาชิกสั้น ๆ เช่น `PZ-XXXX` พร้อมตั้งรหัส PIN 4–6 หลัก
   - แสดงการ์ดแสตมป์สะสมแต้ม 10 ช่อง (Interactive Stamp Card) พร้อมแถบแสดงความคืบหน้าสู่ของรางวัลถัดไป
   - แคตตาล็อกของรางวัล (Rewards Catalog) พร้อมปุ่มกดแลกแต้มและสร้างใบสรุปการแลกรางวัลส่งเข้า LINE ร้านทันที
   - ตรวจสอบประวัติแต้มย้อนหลัง และบันทึกบัตรสะสมแต้มเป็นรูปภาพ `.PNG` สวยงามเก็บไว้ในมือถือ

### 1.2 ระบบหลังบ้านสำหรับแอดมิน (`/admin`)
1. **ระบบล็อกอินปลอดภัย (`/admin/login`):** เข้ารหัสรหัสผ่านด้วย PBKDF2-SHA256, เก็บเซสชันด้วย JWT ใน `httpOnly` Cookie และมีระบบล็อกบัญชีชั่วคราวเมื่อกรอกผิดเกินกำหนด
2. **หน้า Dashboard (`/admin`):** สรุปยอดคำสั่งซื้อ รายได้ประเมิน จำนวนสินค้า/ฟอนต์ คะแนนรีวิวเฉลี่ย และสถิติสมาชิกสะสมแต้ม/คำขอแลกรางวัล
3. **จัดการคำสั่งซื้อ & ผูกสมาชิก (`/admin/orders`):** ดูรายละเอียดบรีฟ เปลี่ยนสถานะออเดอร์ แจกแต้มสะสมอัตโนมัติเมื่อส่งงานเรียบร้อย และมีปุ่มผูกรหัสสมาชิกย้อนหลัง
4. **จัดการสมาชิก & แต้มสะสม (`/admin/members`):** ค้นหาสมาชิก ดูสมุดบัญชีแต้มย้อนหลัง (Points Ledger) ปรับแต้มด้วยตนเอง รีเซ็ตรหัส PIN อนุมัติ/ยกเลิกคำขอแลกของรางวัล และจัดการแคตตาล็อกของรางวัล
5. **จัดการสินค้าและบริการ (`/admin/products`):** เพิ่ม/แก้ไข/ลบ/ซ่อนสินค้า และอัปโหลดรูปปกหรือรูปแกลเลอรีขึ้น Cloudflare R2 ได้ในคลิกเดียว (รองรับมุมมองการ์ดบนมือถือ)
6. **จัดการฟอนต์ (`/admin/fonts`):** อัปโหลดไฟล์ฟอนต์ `.woff2`/`.ttf`/`.otf` สำหรับหน้าทดลองพิมพ์
7. **จัดการรีวิว (`/admin/reviews`):** เปิดแสดง ซ่อน หรือลบรีวิวได้ทันที
8. **ตั้งค่าเว็บไซต์ ธีมสี & กติกาแต้ม (`/admin/settings`):** เปลี่ยนชื่อร้าน ป้ายคิวงาน โลโก้ รูปร้านหน้าแรก ช่องทางติดต่อ โทนสีเว็บไซต์ ผลงานแกลเลอรี คำถามแบบทดสอบฟอนต์ ตั้งค่าระบบสะสมแต้ม ตั้งค่า LINE Messaging API และเปลี่ยนรหัสผ่านแอดมิน

## 2. รายการฟีเจอร์พิเศษที่มอบให้เพิ่มเติม (ของแถมฟรี 🎁)

1. **ระบบสร้างและดาวน์โหลดรูปใบเสร็จคำสั่งซื้อ (`.PNG`) อัตโนมัติ** ให้ลูกค้าเซฟส่งในแชต LINE ได้สะดวก
2. **หน้าแบบทดสอบ "ฟอนต์ไหนคือคุณ" (`/font-quiz`)** พร้อมระบบสร้างการ์ดผลลัพธ์ `.PNG` และแก้ไขคำถามได้จากหลังบ้าน
3. **โหมดสลับพื้นหลังสว่างละมุน / โหมดช็อกโกแลตถนอมสายตา** ที่แถบเมนูด้านบน
4. **ระบบตั้งค่าและปุ่มทดสอบยิงแจ้งเตือน LINE Messaging API ในหน้าหลังบ้าน** ให้ร้านใส่หรือเปลี่ยน Token เองได้ตลอดเวลาโดยไม่ต้องใช้คำสั่งโค้ด
5. **ปุ่มแชต LINE ลอยมุมขวาล่าง (Floating LINE Button)** ให้ลูกค้าทักแชต `@280npxvj` ได้จากทุกหน้า

## 3. เงื่อนไขการดูแลและแก้ไขหลังส่งมอบ (Post-Handover Support)

- **สิทธิ์การแก้ไขงานเล็กน้อยฟรี 2 รอบ (Minor Revisions):**
  - ครอบคลุมการปรับข้อความ คำผิด ขนาดตัวอักษร สีจุดเล็ก ๆ หรือการจัดวางองค์ประกอบย่อยภายในโครงสร้างเดิมของเว็บไซต์
  - แจ้งรวมรายการแก้ไขเป็นรอบ ๆ ภายในระยะเวลา **14 วัน** นับจากวันส่งมอบงาน
- **การรับประกันแก้ไขบั๊ก (Bug Fix Warranty):**
  - หากพบข้อผิดพลาดของระบบที่เกิดจากโค้ดเดิมตามขอบเขตงานนี้ ทางผู้พัฒนาแก้ไขให้ฟรีโดยไม่คิดค่าใช้จ่ายและไม่นับรวมในโควตาการแก้ไข 2 รอบค่ะ

## 4. ข้อจำกัดของระบบ (System Limitations)

เพื่อให้การดูแลรักษาระบบมีความเสถียร ปลอดภัย และไม่มีค่าใช้จ่ายรายเดือนแฝง ระบบมีข้อจำกัดตามสเปกดังนี้ค่ะ:

1. **ไม่รองรับการตอบกลับรีวิวหรือแก้ไขข้อความรีวิวของลูกค้า:** แอดมินสามารถเลือก **"เปิดแสดง"**, **"ซ่อนจากหน้าเว็บ"** หรือ **"ลบรีวิว"** ได้เท่านั้น เพื่อความโปร่งใสของรีวิวร้าน
2. **ไม่มีระบบตัดบัตรเครดิต/เช็กสลิปธนาคารอัตโนมัติบนหน้าเว็บ:** เนื่องจากงานออกแบบป้ายและกราฟิกต้องตรวจสอบบรีฟและคิวงานก่อน ระบบจึงออกแบบให้บันทึกออเดอร์ลงฐานข้อมูลและส่งสรุปเข้าแชต **LINE Official (`@280npxvj`)** เพื่อสรุปคิวและแจ้งยอดโอนโดยตรง
3. **ไม่มีระบบส่งไฟล์ฟอนต์ตัวเต็มให้ดาวน์โหลดอัตโนมัติหน้าเว็บ:** เพื่อป้องกันการคัดลอกหรือดาวน์โหลดไฟล์ฟอนต์ตัวเต็มโดยไม่ได้รับอนุญาต ไฟล์ในหน้าทดลองพิมพ์จะใช้สำหรับแสดงผลตัวอย่างเท่านั้น ส่วนไฟล์ฟอนต์ตัวเต็มแอดมินเป็นผู้จัดส่งให้ลูกค้าหลังชำระเงิน
4. **ไม่ใช้เสียงประกอบทุกชนิดในเว็บไซต์:** ตามกติกาการออกแบบเพื่อให้หน้าเว็บโหลดเร็วและไม่รบกวนผู้ใช้งานบนมือถือ
5. **ขีดจำกัดขนาดไฟล์อัปโหลด:** รองรับการอัปโหลดไฟล์รูปภาพและไฟล์ฟอนต์ขนาดไม่เกิน **5 MB ต่อไฟล์** (ตามข้อจำกัดความเร็วและความปลอดภัยของ Cloudflare Workers)
